Setup for the YouTube auto-post (Instagram comes later). Do this on the computer that runs the server.
STEP 1: Get the new code
Merge the pull request (branch: social-autopost) or download the new files. You should have backend/social.py.

STEP 2: Install ffmpeg (a free program that makes the video)
- Windows: open PowerShell and run:  winget install ffmpeg
  then CLOSE the terminal and open a new one.
- Mac:  brew install ffmpeg
Check it worked:  ffmpeg -version   (it should print version info)

STEP 3: Fill in the .env file
1. Open backend/.env.social.example. Copy its lines.
2. Paste them at the bottom of backend/.env. Do NOT delete the Naver / POSTECH keys that are already there. If .env does not exist, create it.
3. Fill in the values I sent you:
   YT_CLIENT_ID=...
   YT_CLIENT_SECRET=...
4. Set these for now:
   SOCIAL_PLATFORMS=youtube
   SOCIAL_AUTOPOST=0
   (We turn autopost on at the end. Instagram is not ready yet, so only youtube.)

STEP 4: Login to YouTube (ONE TIME ONLY, you must run this file)
Open a terminal in the backend folder and run:
   python social.py --youtube-login
A browser opens. Sign in with the project Google account. If you see 'Google hasn't verified this app', click Advanced > Continue. Allow the permission.
The terminal prints a line starting with YT_REFRESH_TOKEN=...  Copy that whole line into backend/.env and save.

STEP 5: Quick test (recommended, posts nothing)
You need one product that is already registered in the store from the dashboard. Look at its draft number, then run:
   python social.py <draft_number> --dry-run --no-llm
It prints a caption and makes a video file in backend/exports/social/. Open the video and check it looks OK.
Optional real test (uploads a PRIVATE video):  python social.py <draft_number> --platform youtube
Check results with:  python social.py --status

STEP 6: Turn on automatic posting
In .env change  SOCIAL_AUTOPOST=0  to  SOCIAL_AUTOPOST=1 , then restart the server (python server.py).
From now on the server does everything by itself: when you register a product in the store from the dashboard, the YouTube video is made and uploaded automatically. You do not run any file again. Results appear in the dashboard Activity log.

If something goes wrong:
- Stop everything:  python social.py --pause   (restart with --resume)
- Show errors:  python social.py --status  (send me the message)
- The YouTube login expires after 7 days. If posting fails with a login error, repeat STEP 4.


안녕! YouTube 자동 업로드 설정 방법이야 (Instagram은 나중에). 서버를 실행하는 컴퓨터에서 진행해줘.

1단계: 새 코드 받기
pull request(브랜치: social-autopost)를 merge하거나 새 파일을 내려받아줘. backend/social.py 파일이 있어야 해.

2단계: ffmpeg 설치 (영상을 만들어주는 무료 프로그램)
- Windows: PowerShell을 열고 아래 실행
  winget install ffmpeg
  그 다음 터미널을 완전히 닫고 새로 열어줘.
- Mac:  brew install ffmpeg
설치 확인:  ffmpeg -version  (버전 정보가 나오면 성공)

3단계: .env 파일 채우기
1. backend/.env.social.example 파일을 열고 내용을 복사해.
2. backend/.env 파일 맨 아래에 붙여넣어. 기존에 있는 Naver / POSTECH 키는 절대 지우지 마! .env 파일이 없으면 새로 만들어.
3. 내가 보낸 값을 입력해:
   YT_CLIENT_ID=...
   YT_CLIENT_SECRET=...
4. 일단 이렇게 설정해:
   SOCIAL_PLATFORMS=youtube
   SOCIAL_AUTOPOST=0
   (자동 게시는 마지막에 켤 거야. Instagram은 아직 준비가 안 돼서 youtube만.)
.env 파일은 절대 GitHub에 올리면 안 돼.

4단계: YouTube 로그인 (처음 딱 한 번, 이 파일은 직접 실행해야 해)
backend 폴더에서 터미널을 열고 실행:
   python social.py --youtube-login
브라우저가 열려. 프로젝트용 Google 계정으로 로그인해. '확인되지 않은 앱' 경고가 나오면 고급 > 계속을 눌러. 권한을 허용해줘.
터미널에 YT_REFRESH_TOKEN=... 으로 시작하는 줄이 출력돼. 그 줄 전체를 backend/.env 에 붙여넣고 저장해.

5단계: 간단한 테스트 (권장, 실제로 올리지는 않음)
대시보드에서 스토어에 이미 등록된 상품이 하나 필요해. 그 상품의 draft 번호를 확인하고 실행:
   python social.py <draft번호> --dry-run --no-llm
캡션이 출력되고 backend/exports/social/ 폴더에 영상이 만들어져. 영상을 열어서 괜찮은지 확인해줘.
선택: 실제 업로드 테스트 (비공개 영상):  python social.py <draft번호> --platform youtube
결과 확인:  python social.py --status

6단계: 자동 게시 켜기
.env 에서  SOCIAL_AUTOPOST=0  을  SOCIAL_AUTOPOST=1  로 바꾸고 서버를 다시 시작해 (python server.py).
이제부터는 서버가 알아서 다 해: 대시보드에서 상품을 스토어에 등록하면 YouTube 영상이 자동으로 만들어져서 업로드돼. 더 이상 파일을 직접 실행할 필요 없어. 결과는 대시보드 Activity log에 나와.

문제가 생기면:
- 전부 멈추기:  python social.py --pause  (다시 켜기: --resume)
- 에러 보기:  python social.py --status  (나온 메시지를 나한테 보내줘)
- YouTube 로그인은 7일 후 만료돼. 로그인 오류로 실패하면 4단계를 다시 해줘
